# 2. 首页主插图（必做）

**用途**：首页大标题上方的插图（示意图 A 里虚线框的位置，显示约 420×240，高清屏要 2 倍以上）。
**尺寸**：横图 16:9，至少 1600×900，透明背景（不行就纯白背景）。
**要的感觉**：干净、轻盈、有科技感但不冷。一台漂浮在柔和云朵上的 3D 服务器，旁边一个大的「一键」按钮 / 光标在点它，服务器上方冒出一个发光的对勾面板窗口，表示「一键装好」。四周点缀几个小的悬浮元素（齿轮、盾牌锁、地球），都是同一套配色。

## 提示词（英文，直接复制）

```
Soft 3D isometric illustration for a software landing page, a sleek white server tower floating on soft pastel clouds, a large glossy rounded button with a mouse cursor clicking it, above the server a floating browser-style dashboard window with a glowing green check mark, small floating elements around: a gear, a shield with a padlock, a tiny globe, all rendered in clay-like soft 3D with smooth matte surfaces, color palette of white, light lavender, royal blue #2456F5 and violet #5B3DF5 gradients with tiny emerald green accents, soft diffused studio lighting, gentle shadows, airy and minimal, lots of negative space, centered composition, transparent background, no text, no letters, no numbers, no logos, no watermark --ar 16:9 --style raw --v 7
```

## 中文版

```
软件官网用的柔和 3D 等距插画：一台简洁的白色服务器漂浮在淡彩色的云朵上，旁边一个大大的圆润光滑按钮正被鼠标光标点击，服务器上方飘着一个浏览器样式的面板窗口，窗口中间是一个发光的绿色对勾；周围点缀几个小的悬浮元素：齿轮、带锁的盾牌、小地球。整体是黏土质感的柔和 3D，表面哑光平滑，配色为白色、浅淡紫、蓝色 #2456F5 和紫色 #5B3DF5 的渐变，少量翠绿色点缀，柔和的漫射光，阴影很淡，轻盈简约，大量留白，居中构图，透明背景，不要任何文字、字母、数字、Logo、水印
```

## 备注

- 画面主体尽量集中在中间，左右两边留空，方便在窄屏上裁切。
- 如果出来的图太花，加一句 `fewer elements, simpler` / 「元素再少一些，更简洁」。
