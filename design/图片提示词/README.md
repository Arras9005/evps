# 作图说明

一共 3 张：**1 和 2 必做，3 可选**。每张的提示词在单独的文件里，整段复制过去就行。

| 编号 | 文件 | 用在哪 | 尺寸 | 生成好后存成 |
|---|---|---|---|---|
| 1 | `1-logo.md` | 左上角 Logo、浏览器标签页小图标 | 1024×1024 正方形 | `生成结果/logo.png` |
| 2 | `2-hero.md` | 首页大插图（示意图 A） | 横图 16:9，至少 1600×900 | `生成结果/hero.png` |
| 3 | `3-done.md`（可选） | 「面板装好了」页顶上的小插图（示意图 E） | 1024×1024 正方形 | `生成结果/done.png` |

## 几点要求

- **背景要透明**（PNG）。工具做不了透明的话，就用**纯白背景**，我来抠。
- **图上不要有任何文字、字母、数字、Logo 水印。**
- 三张要像同一套：都用提示词里的同一种风格和配色（蓝紫渐变 `#2456F5 → #5B3DF5`、白色、浅淡紫）。
- 每张多出几张，挑你最喜欢的一张放进 `生成结果/`；拿不准的话可以都放进去，文件名加 `-2`、`-3`，我来挑。
- 推荐工具：ChatGPT（GPT-Image，能出透明背景）、Midjourney、即梦、可灵都可以。Midjourney 的参数（`--ar` 等）已经写在提示词末尾，用别的工具时删掉那部分。
