# evps 界面改造方案（待确认）

> 示意图在 `design/mockup/`（A–H 八张），现在的界面截图在 `design/当前界面/`。
> 作图提示词在 `design/图片提示词/`。
> 本方案**只改网页**（`web/src`），后端、一行命令、VPS 脚本都不动。

---

## 一、现在哪里别扭

**操作上**

1. **新服务器的表单上就摆着 5 个按钮**：安装、查看状态、停止、启动 / 重启、卸载。第一次用的人只需要「安装」，另外 4 个按钮又让人犹豫：还没装呢，卸载什么？
2. **进度和结果接在表单下面**，页面越拉越长，还会自动往下滚。装好以后，登录信息被压在 9 个「✓」下面，最重要的东西反而不显眼。
3. **打开记住的服务器时什么都看不到**：不知道面板在运行还是已经停了，得先点「查看状态」。按钮也不看状态，面板已经停了，「停止」照样摆着。
4. **点「我还没有 VPS」直接弹出新标签页**，同时本页也跳走了，人会愣一下：我现在该看哪边？
5. **表单要填 4 项**：端口和用户名 99% 的人不用改，却和 IP、密码一样显眼。
6. **退出、清理本机文件、忘记服务器用的是浏览器自带的弹窗**，样子和别处的确认框不一样，看着像出错。

**观感上**

- 内容挤在一块 900px 宽的区域里，字小、按钮小，边框和底色块很多，显得「后台管理系统」味很重，不够大气。
- 首页两张卡片分量一样，看不出主路线是哪条。
- 没有任何图形元素，只有字和框。

---

## 二、新思路（三句话）

1. **一页只做一件事**：首页 → 连接服务器 → 安装中 → 装好了，像向导一样一步一步往前走，不在一页上堆东西。
2. **按钮跟着状态走**：只显示现在能做、该做的操作，最该点的那个做得最显眼；卸载这种危险操作收到最下面的小字里。
3. **大留白、大字、少边框**：一列居中，宽 560–720px；标题 26–40px；输入框和主按钮高 52px；卡片用柔和阴影代替边框；整页一个蓝紫渐变主色。

## 三、逐页说明（对照 `design/mockup/`）

### A 首页 · 第一次用（`A-首页-第一次.png`）
- 上方一张主插图（hero.png，需要作图）。
- 大标题「一键给你的 VPS 装好 Geto 面板」，副标题一句话。
- **只有一个主按钮「开始安装」**。「还没有服务器？看看推荐 →」降为文字链接。
- 底部一行小字：密码只在这台电脑上用 · 开源免费 · 非面板官方工具。
- 右上角「···」菜单，退出、清理本机文件都放进去（见 H）。

### B 首页 · 已有服务器（`B-首页-我的服务器.png`）
- 有记住的服务器时，首页直接变成「我的服务器」列表。
- **打开页面就自动查一遍每台的状态**，标出「运行中 / 已停止 / 未安装 / 连不上」。
- 右上角「＋ 添加服务器」；底部保留「看看推荐」链接。

### C 连接服务器（`C-连接服务器.png`）
- 顶部有「① 连接服务器 — ② 安装 — ③ 完成」步骤条，让人知道一共几步。
- 服务器 IP、root 密码在上面；SSH 端口（默认 22）和用户名（默认 root）并排放在下面，**直接显示，不用点开**（2026-11-21 用户要求，原来收在「高级」里）。粘贴 `root@IP:端口` 照样自动拆开。
- 「记住这台服务器」只留一句话；放公钥那句解释改成鼠标移上去才显示的小问号。
- 一个大按钮「连接并安装」。
- **出错（密码不对、连不上）时，错误就显示在按钮上方，表单保持原样，改完再点。**
- 如果这台服务器其实已经装过面板，不会重装，直接跳到「装好了 / 服务器详情」，显示现在的登录信息（后端本来就会这样判断）。

### D 安装中（`D-安装中.png`）
- 表单收起，整页只看进度：中间一个圆环写「4 / 9」（按步骤数算，不编假的百分比）。
- 圆环下面一行大字说明正在做什么，再写「大约要几分钟，请别关这个网页和黑窗口」。
- 步骤列表变简洁：做完的打勾，正在做的转圈，后面没做的合成一行灰字。
- 「查看详细日志」默认收起。
- **失败时**：圆环变红，大字写失败原因（沿用现在的中文提示），日志自动展开，下面给「重试」和「返回修改」两个按钮。

### E 装好了（`E-装好了.png`）
- 大绿勾 +「面板装好了」。
- **登录信息就是这一页的主角**：面板地址、用户名、密码三行，每行右边一个「复制」。
- 下面两个大按钮：「打开面板 ↗」（主按钮）、「复制全部」。
- 从你的电脑连不上面板端口时，黄色提示条出现在三行信息下面（同 F）。
- 「管理这台服务器 →」进入详情页。

### F 服务器详情（`F-服务器详情.png`）
- 顶部：大字 IP，下面小字「root · SSH 端口 22 · 已记住」，右边状态标签。
- **一进来就自动查状态**，查的时候显示骨架占位，不用手点。
- 中间卡片：登录信息三行 + 端口连不上的提示（如果有）+ 操作按钮。
- **按钮按状态变化**：
  - 运行中：「打开面板」（主）、「重启」、「停止」
  - 已停止：「启动」（主）
  - 未安装：「安装面板」（主）
- 最底下一行小字：刷新状态 · 卸载面板（红字）· 忘记这台服务器。
- 停止、重启、卸载执行时，按钮变转圈，结果用顶部小提示 + 状态标签更新，不再往页面底下加一张卡片。卸载照旧先弹确认框。
- 没勾「记住」的服务器：这次打开 evps 期间还能在详情页里继续操作（密码只放在网页内存里），关掉网页就忘了。

### G 买服务器（`G-买服务器.png`）
- **不再自动弹新标签页。** 进来先看到服务商卡片、推荐理由、购买注意，点「去购买 ↗」才打开。
- 文字照用 `promo.json` 里的原话（示意图里是缩写）。
- 底部「买好了，开始安装 →」直接进 C。

### H 右上角菜单（`H-右上角菜单.png`）
- 「退出 evps」「清理本机文件并退出」（红字）、版本号 · GitHub 链接。
- 退出、清理、忘记服务器都改用页面里自己的确认框，不用浏览器自带的弹窗。

## 四、视觉规范

| 项 | 取值 |
|---|---|
| 主色 | 蓝紫渐变 `#2456F5 → #5B3DF5`，只用在主按钮、Logo、选中状态 |
| 背景 | `#F7F9FC`，顶部一团很淡的蓝色光晕 |
| 文字 | 主 `#0F172A`，次 `#64748B`，弱 `#94A3B8` |
| 状态色 | 运行中 绿 `#10B981`，已停止 琥珀 `#F59E0B`，错误 红 `#EF4444` |
| 字号 | 首页大标题 40px，页面标题 26px，正文 15–17px，说明 13px |
| 尺寸 | 输入框、主按钮高 52px；圆角：按钮 14px，卡片 20px |
| 字体 | 中文 PingFang SC / 微软雅黑；IP、密码这类用等宽字体 |
| 宽度 | 一列居中：表单 560px，列表 720px；手机上铺满并留 20px 边距 |
| 深色模式 | 保留，照旧跟随系统；同一套颜色出深色版本 |
| 动效 | 只有换页淡入、按钮按下、圆环转动，都很轻 |

## 五、需要你拍板的 4 件事

1. ~~「记住这台服务器」默认勾上？~~ **已定（2026-11-21）：默认勾上。**
2. **「还没有 VPS」不再自动弹新标签页**，改成看完说明再点「去购买」。同意吗？
3. **首页自动查每台记住的服务器的状态**：每台要 SSH 连一次，大约 1–3 秒，几台一起查。同意吗？（不同意的话就只在进详情页时查。）
4. **作图**：需要 2 张必做 + 1 张可选（见 `design/图片提示词/README.md`）。也可以先不作图，用纯色和图标顶上，图到了再换。

## 六、不变的东西

- 后端接口、一行命令启动、VPS 脚本、便携 Node：都不改。
- 安全上的约束照旧：密码不离开本机、只听 127.0.0.1 + 令牌、内容安全策略（图片会打包成独立文件，不内联，免得被策略拦住）。
- 所有中文提示、出错说明的措辞照旧，只是换个位置放。

## 七、实现和验收

1. 换新的设计变量和样式（`web/src/styles/`），加图片资源（压成 WebP，每张控制在 100KB 内，npm 包不会变大多少）。
2. 重写页面组件：首页、我的服务器、连接、安装进度、装好了、服务器详情、购买、菜单、确认框。
3. 界面走查脚本 `dev/walkthrough.mjs` 按新流程改，浅色、深色、窄屏都截一遍；README 配图重拍。
4. `npm run verify`（类型检查 + 测试 + 构建）全部通过后提交推送。
